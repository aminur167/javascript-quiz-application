# JavaScript Quiz Application

Modular quiz application with timed questions, score tracking, and detailed answer review.

## Features

- Multiple-choice question interface
- Countdown timer per question
- Score calculation and percentage display
- Answer review showing correct/incorrect responses
- Question randomization
- Clean and intuitive UI

## Project Structure

```
index.html     - Main quiz interface
style.css      - Quiz layout and styling
js/
  questions.js - Question bank
  quiz.js      - Quiz logic and state management
img/           - UI assets
```
